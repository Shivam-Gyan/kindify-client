# Kindify Client

A frontend part of web application dedicated to spreading kindness through charitable donations and positive messages.

## Overview

Kindify is a platform that connects donors with causes, making it easy to share kindness and support those in need. This repository contains the client-side code built with React, TypeScript, and Vite.

## Tech Stack

- React 18
- TypeScript
- Vite
- ESLint
- CSS Modules
